# Coach Max — Personal Training Presencial

Página estática em HTML, CSS e JavaScript puro para apresentar o acompanhamento presencial e encaminhar interessados ao WhatsApp.

## Visualização pelo GitHub Pages
Depois que o GitHub Pages publicar a branch main, acesse:
https://gusdias-coder.github.io/CoachMax/personal-presencial/

## Arquivos
- index.html — conteúdo da página
- style.css — identidade visual e responsividade
- script.js — menu, animações e links do WhatsApp
